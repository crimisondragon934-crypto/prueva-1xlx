# Prueva-1XLX: Local LLM for Android 12 (8GB RAM)

Native Flutter + `llama.cpp` (`fllama`) offline AI assistant with local text/file training.

## Compatible Models (`.gguf` format)
- **Gemma 2 2B Instruct (`Q4_K_M`)** — ~1.6 GB RAM (Fastest)
- **Llama 3.2 3B Instruct (`Q4_K_M`)** — ~2.0 GB RAM (Balanced)
- **Phi-3.5 Mini Instruct (`Q4_K_M`)** — ~2.4 GB RAM (Best reasoning)
